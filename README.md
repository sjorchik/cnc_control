# CNC Control STM32 — пульт керування для FluidNC

Окремий пульт (контролер інтерфейсу) на **STM32F103CBT6** (Blue Pill) для керування ЧПУ / лазерним верстатом під прошивкою **FluidNC** на ESP32. Пульт має кольоровий TFT-дисплей 320×240 на ILI9341, клавіатуру на **TM1638** і читає файли з SD-карти FluidNC, щоб запускати їх прямо з пульта.

## Можливості

- Живе відображення стану: `IDLE / RUN / HOLD / JOG / HOME / ALARM / NO LINK`, машинні та робочі координати (MPos / WPos), F і S, поточний файл і прогрес, IP-адреса контролера.
- Ручний джог осей X / Y / Z з кроками `0.1 / 1 / 10 / 100` або безперервним рухом.
- Нуль осей (XY0, Z0, окремо X/Y/Z через `G10 L20`), пробування висоти інструмента (`G38.6`), `$H` (домашня позиція) і `$X` (розблокування).
- Оверрайди подачі та шпинделя / потужності в режимі RUN, кнопки HOLD / START / RESET.
- Профілі **SPINDLE** і **LASER**: перемикання довгим натисканням кнопки шпинделя. Якщо шпиндель / лазер увімкнено, пульт одразу застосовує команду нового профілю.
- Список файлів на SD-карті FluidNC та запуск обраного файлу.
- Збереження налаштувань (подача, режим джога, профіль, потужності профілів) у flash-пам'яті МК.
- Автоповтор для осьових кнопок (утримання).

## Апаратна частина

| Компонент | Призначення |
|---|---|
| STM32F103CBT6 (Blue Pill) | Головний контролер пульта |
| ILI9341 (SPI TFT, 320×240) | Дисплей |
| TM1638 (модуль кнопок і світлодіодів) | Клавіатура |
| ESP32 з FluidNC | Контролер верстата |

### Підключення (за `board.h`)

| Сигнал | Пін STM32 |
|---|---|
| LCD CS | PA3 |
| LCD DC | PA2 |
| LCD RST | PA0 |
| SPI1 SCK / MOSI | PA5 / PA7 |
| TM1638 STB | PC13 |
| TM1638 CLK | PC14 |
| TM1638 DIO | PC15 |
| UART до FluidNC: USART1 TX / RX | PA9 / PA10 (115200 бод) |

Підключіть GND пульта і ESP32 разом, інакше обмін по UART працюватиме ненадійно.

## Підготовка FluidNC

Пульт надсилає до FluidNC такі команди:

- `$ESP111` — запит IP-адреси (для відображення на екрані);
- `$ESP210` — запит списку файлів на SD-карті;
- `$ESP220=sd/<файл>` — запуск файлу з SD.

Переконайтеся, що ваша версія FluidNC їх підтримує: відкрийте консоль або вебінтерфейс і перевірте, що список файлів з SD та запуск працюють. Пульт не використовує патчів, які додають нові команди.

## Збірка та прошивка пульта

Проєкт створено в **STM32CubeIDE** (конфігурація в `cnc_control_stm32.ioc`).

1. Відкрийте папку проєкту в STM32CubeIDE (`File → Import → Existing Projects into Workspace`).
2. Зберіть конфігурацію `Debug` (`Project → Build Project`).
3. Прошийте через ST-Link (`Run → Debug` або STM32CubeProgrammer) або через USB-UART з bootloader.

Налаштування зберігаються на сторінці flash `0x0800F800` з міткою `MAGIC = 0xC0DF`. Якщо змінюєте структуру `settings_t`, змініть `MAGIC`, щоб старі дані скинулися.

Папка `Debug/` містить артефакти збірки (`.elf`, `.hex`, `.bin`, `.map`). Її зазвичай не комітять у репозиторій, окрім, можливо, готового `.hex` для прошивки.

## Структура проєкту

```
Core/Src, Core/Inc     — код застосунку
  main.c               — ініціалізація периферії (SPI1, USART1, DMA, GPIO)
  ui.c / ui.h          — екрани (головний, SD-список), обробка кнопок
  fluidnc.c / .h       — UART-протокол з FluidNC, статус, команди, SD-список
  settings.c / .h      — збереження налаштувань у flash
  ili9341.c / .h       — драйвер дисплея
  tm1638.c / .h        — драйвер клавіатури (з автоповтором для осьових кнопок)
  board.h              — призначення пінів
  font5x7.h            — шрифт
Drivers/                — HAL та CMSIS (ST)
Debug/                  — артефакти збірки STM32CubeIDE
```

## Використання

**Головний екран.** Кнопки X / Y / Z (+ і −) дають джог, кнопки подачі й потужності змінюють оверрайди в режимі RUN. Кнопка HOLD ставить на паузу, START продовжує, RST робить soft reset (`0x18`). Кнопка `$X` знімає блокування.

**Перемикання профілю.** Довге натискання (близько 0.8 с) кнопки шпинделя в режимі очікування перемикає SPINDLE ↔ LASER. Якщо шпиндель був увімкнений, пульт одразу надсилає команду `M3` з потужністю нового профілю.

**SD-список.** Відкривається кнопкою SD. Y+ / Y- вибирають файл, **XY0** запускає вибраний файл, **RST** повертає на головний екран.

## ⚠️ Безпека

- **Перевіряйте профіль перед запуском.** Профіль SPINDLE / LASER зберігається між сесіями. Переконайтеся, що він відповідає інструменту на верстаті, перш ніж запускати файл.
- **Лазер:** надягайте захисні окуляри, не залишайте лазер без нагляду, перевіряйте шлях на холостому ході.
- **Фреза:** перед запуском переконайтеся, що заготовка закріплена, а висота Z безпечна. Функція пробування (`G38.6`) рухає інструмент до датчика, тож перевірте шлях.
- Пульт не замінює апаратну аварійну кнопку верстата. Використовуйте E-stop.

## Відомі обмеження

- Пульт не сканує габарити (bbox) файлу і не має функції обводу периметра. Для перевірки зони роботи використовуйте інші засоби (наприклад, пробний прохід без лазера або з мінімальною потужністю).
- Частина написів і коментарів у коді українською мовою.
